# Campus Event Hub 🎉

Campus Event Hub is a full-stack event management platform designed for colleges and student communities to simplify event organization, registrations, QR-based entry verification, and participant management.

---

## 🚀 Features

### 👨‍🎓 User Features
- User Registration & Login
- Browse Upcoming Events
- Event Registration
- QR Code Ticket Generation
- Email Confirmation Tickets
- View Registered Events

### 🛠 Admin Features
- Create / Update / Delete Events
- Manage Registrations
- QR Scanner Verification
- Dashboard Analytics
- Participant Management

---

## 🧩 Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java Spring Boot
- Spring Data JPA
- Hibernate
- REST APIs

### Database
- PostgreSQL (Render Database)

### Deployment
- Render + Docker
